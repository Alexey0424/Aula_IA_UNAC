FORMATO DE ENTRADA ESPERADO  (.npz de numpy)
  Se genera con:  np.savez_compressed(destino, X=X, y=y, clases=np.array(CLASES))
  Se lee con:     np.load(ruta, allow_pickle=False)

  Las TRES llaves son exactamente estas. Verificado sobre el archivo real:
    X       (N, 28, 28)  float32, valores 0.0 a 1.0
    y       (N,)         int64, enteros 0..C-1
    clases  (C,)         array de texto con los nombres, en el orden de y
            (ejemplo real: ['OK' 'Rayon' 'Burbuja' 'Astillado'])

  OJO: el loader usa allow_pickle=False. Por eso 'clases' tiene que ser un
  array de texto de numpy (dtype <U...), NUNCA una lista de Python ni un array
  de dtype=object: con object el np.load falla.

  Escala de grises, no color (un solo canal, sin la dimension de color).
  28 x 28 pixeles.
  Minimo razonable: 200 imagenes por clase. Por debajo de eso es un ejercicio,
  no una herramienta, y hay que decirlo.

CONVERSION DE IMAGENES REALES - reglas
  - Una subcarpeta por clase; el nombre de la subcarpeta es la etiqueta.
  - Redimensionar a 28x28 SOLO si el defecto sobrevive al encogido. Una grieta
    de un pixel de ancho no sobrevive: en ese caso hay que subir la resolucion
    y ajustar la red, y hay que advertirlo antes de entrenar.
  - Normalizar a 0.0-1.0 dividiendo por 255.
  - Revisar el desbalance entre clases y reportarlo.
  - REVISAR FONDOS: si las clases se tomaron en escenarios distintos, la red
    aprende el fondo. Es el error mas comun con fotos reales y hay que
    advertirlo explicitamente antes de celebrar cualquier metrica.

ERRORES COMUNES Y QUE SIGNIFICAN
  ModuleNotFoundError: No module named 'torch'
      Python equivocado, o no se creo env_deep. Ver 0_instalar.txt PASO 2.
  OSError: [WinError 1114] ... c10.dll
      Se instalo torch en un entorno con numpy 1.x (el de PyCaret). No se
      arregla con --upgrade numpy: eso rompe PyCaret. Se crea env_deep aparte.
  KeyError: 'X' (o 'y', o 'clases')
      El .npz se genero con otras llaves. Las tres son X, y, clases.
      Ver FORMATO DE ENTRADA arriba.
  ValueError: Object arrays cannot be loaded when allow_pickle=False
      'clases' quedo como lista de Python o array de dtype=object. Debe ser
      np.array de texto.
  ValueError: shapes ... not aligned
      Las imagenes no quedaron en 28x28, o quedaron en color (3 canales).
  Accuracy del clasico parecido al de la CNN
      Con imagenes muy centradas y muy limpias puede pasar. Es un resultado
      legitimo y se reporta: significa que para ESE problema no hacia falta
      una red convolucional. No se maquilla.
  Accuracy >= 0.98 con fotos reales
      Sospeche de fuga por el fondo o por imagenes duplicadas entre estudio y
      examen ANTES de reportar el resultado.
