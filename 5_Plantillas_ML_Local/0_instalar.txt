 AVISO - POR QUE SON DOS INSTALACIONES SEPARADAS Y NO UNA
===============================================================================

  Las tres plantillas NO pueden vivir en la misma instalacion de Python.

  Plantilla 1 usa PyCaret, que exige numpy version 1.
  Plantillas 2 y 3 usan PyTorch, que exige numpy version 2.

  numpy es la libreria de calculo que esta por debajo de todo. Solo puede
  haber UNA version instalada a la vez. No hay forma de tener las dos.

  QUE PASA SI LAS MEZCLA - esto lo probamos, no lo estamos suponiendo:

    Si instala PyCaret y despues PyTorch en el mismo Python, PyTorch queda
    roto. Y lo peor: queda roto EN SILENCIO. pip le dice
    "Successfully installed torch" y no se queja de nada. El error aparece
    despues, cuando corre la plantilla 3:

        OSError: [WinError 1114] A dynamic link library (DLL) initialization
        routine failed. Error loading "...\torch\lib\c10.dll"

    Y si trata de arreglarlo subiendo numpy, entonces se rompe PyCaret:

        ValueError: numpy.dtype size changed, may indicate binary
        incompatibility. Expected 96 from C header, got 88 from PyObject

    Arregla una y rompe la otra. Es un techo, no un problema de configuracion.

  LA SOLUCION: dos "cuartos" de Python separados, que no se ven entre si. Se
  llaman entornos virtuales. Se crean una vez y no se vuelven a tocar:

        C:\ia\env_pycaret     ->  Plantilla 1  (PyCaret / AutoML)
        C:\ia\env_deep        ->  Plantillas 2 y 3  (PyTorch)

  No tiene que entender como funcionan. Solo tiene que copiar y pegar las
  lineas de abajo en el orden en que estan.

  POR QUE EN C:\ia Y NO AQUI MISMO: Windows no aguanta rutas de mas de 260
  caracteres y PyTorch tiene nombres de archivo larguisimos por dentro. En una
  carpeta profunda la instalacion falla; en C:\ia funciona siempre. Verificado.

 PASO 0 - VERIFICAR QUE TIENE PYTHON   (10 segundos)
===============================================================================

Copie y pegue esta linea:

    py --version

  Si responde algo como "Python 3.12.10", ya esta. Siga al PASO 1.

  Si dice que no reconoce el comando, o si se le ABRE LA TIENDA DE MICROSOFT,
  no tiene Python instalado. Baje el instalador de:

      https://www.python.org/downloads/windows/

  y en la primera pantalla del instalador MARQUE la casilla
  "Add python.exe to PATH" antes de darle Install. Es la casilla que todo el
  mundo se salta y es la que causa el 90 % de los problemas.

 PASO 2 - EL ENTORNO DE PYTORCH   (para las plantillas 2 y 3)
===============================================================================

  *** ESTA NO SE CORRE EN CLASE. ***
  Son mas de 1.000 MB. Con 16 personas bajando eso al mismo tiempo, el salon
  se queda sin internet. Las plantillas 2 y 3 son TAREA PARA LA CASA.

Copie y pegue las DOS lineas, una despues de la otra:

    py -m venv C:\ia\env_deep

    C:\ia\env_deep\Scripts\python.exe -m pip install torch scikit-learn pandas matplotlib numpy

  Disco     : 1.003 MB    (medido, un poco mas de 1 GB)
  Tiempo    : 3 a 6 minutos con internet decente
  Paquetes  : 31

  VERIFIQUE que quedo bien:

    C:\ia\env_deep\Scripts\python.exe -c "import torch, sklearn, matplotlib; print('PASO 2 OK - torch', torch.__version__)"

  Debe decir algo como: PASO 2 OK - torch 2.13.0+cpu

  Ese "+cpu" al final es la confirmacion de que quedo la version liviana.

  TRES COSAS VERIFICADAS QUE LE AHORRAN DOLORES DE CABEZA:

  1. En WINDOWS esa linea trae la version de CPU y nada mas. NO necesita
     tarjeta grafica, NO necesita CUDA y NO necesita el famoso
     "--index-url https://download.pytorch.org/whl/cpu" que sale en los
     tutoriales. Todas las dependencias de NVIDIA de PyTorch estan marcadas
     "solo Linux", asi que en Windows no se bajan. Verificado el 26-ago-2026.

  2. Si le sale un error que menciona "long paths" o "ruta demasiado larga":
     es el limite de 260 caracteres de Windows. Por eso el entorno va en
     C:\ia y no dentro de esta carpeta. Si igual le pasa, mueva TAMBIEN la
     carpeta de las plantillas a una ruta corta como C:\plantillas\ .

  3. Si prefiere no instalar PyTorch nunca, no pasa nada: la plantilla 1 es
     completa por si sola y le sirve igual para el proyecto de grado.

  Pero usted casi nunca va a escribir esto a mano: cada carpeta trae un

  NO SE EQUIVOQUE DE ENTORNO. Si corre la plantilla 1 con el Python de

      ModuleNotFoundError: No module named 'torch'

  Los dos errores significan lo mismo: se equivoco de Python. No falta
  instalar nada. No instale nada. Solo cambie la linea.


===============================================================================
 LO QUE NUNCA HAY QUE HACER   (aqui es donde se rompe todo)
===============================================================================

  1. NO instale PyTorch en el entorno de PyCaret.
     NO instale PyCaret en el entorno de PyTorch.
     Es exactamente lo que rompe la instalacion, y rompe en silencio.

  2. NO corra "pip install --upgrade numpy" para arreglar un error.
     Es el arreglo que parece obvio y es el que garantiza el problema:
     arregla un entorno y rompe el otro.

  3. NO instale nada con "py -m pip install ..." mientras trabaja con las
     plantillas. Ese "py" es el Python del sistema, que no es ninguno de los
     dos entornos. Todo lo que instale ahi no le va a servir.

  4. SI ALGO SE ROMPIO, no lo repare: borrelo y vuelvalo a crear. Es mas
     rapido y siempre funciona:

        Remove-Item -Recurse -Force C:\ia\env_pycaret
        (y repita el PASO 1)

     Borrar un entorno virtual no le hace nada a su computador ni a su
     Python. Es una carpeta y nada mas.
