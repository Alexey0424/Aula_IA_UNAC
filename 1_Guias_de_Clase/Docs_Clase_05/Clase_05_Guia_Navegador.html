Que Claude maneje su navegador

Hasta hoy usted le pedia cosas y Claude le contestaba. De aqui en adelante Claude abre el navegador, hace clic, escribe y llena. Se llama agente de navegador — en ingles, browser use.

La extension se llama Claude in Chrome y funciona tambien en Brave y en Edge. Al terminar esta guia usted le va a decir «abri esta pagina y escribime el resultado en la hoja», y va a pasar.

Antes de empezar. Necesita Claude Code funcionando (Clase 02) y haber entrado con /login. Si entro con una API key, esto no va a funcionar y no es culpa suya: la extension no puede autenticarse con API key. Avise en clase.
1

Instale la extension en UN solo navegador

Escoja uno. Chrome, Brave o Edge. Uno.
  1. Abra el navegador que va a usar y entre a la Chrome Web Store: chromewebstore.google.com
  2. Busque la extension llamada Claude, publicada por Anthropic.
  3. Añadir a Chrome (en Brave dice lo mismo).
  4. Inicie sesion en la extension con la cuenta de Claude.
  5. Anclela: el icono de la pieza de rompecabezas arriba a la derecha, y el chinche.
  6. Cierre el navegador y abralo otra vez. No es opcional.
Lo mas importante de todo esta guia: instalela en UN solo navegador. Si la pone en Chrome y en Brave, su computador se registra dos veces y despues Claude le va a preguntar «¿el 1 o el 2?» toda la clase. Si ya la tiene en varios, quitela de los que no va a usar.
¿Por que hay que reiniciar el navegador? Porque el navegador lee la configuracion de la conexion solo al arrancar. Si no lo reinicia, Claude Code le va a decir que no encuentra la extension y usted va a pensar que quedo mal instalada.
2

Conectela a Claude Code

Una bandera y un comando.

En la terminal de Visual Studio Code, en vez de escribir claude, escriba:

Escriba esto en la terminal 
claude --chrome

La primera vez le sale un aviso que le explica como funcionan los permisos por sitio. Lealo y dele Enter.

Ahora, adentro de Claude Code, escriba:

Escriba esto adentro de Claude Code 
/chrome
Como sabe que quedo bien: el panel le muestra Status: Enabled y Extension: Installed. Esas dos lineas. Si dice Not detected, vuelva al paso 1 y reinicie el navegador.
ComandoPara que sirve
claude --chromeArranca la sesion con el navegador conectado
/chromeVer el estado, reconectar, escoger navegador
/chrome → Reconnect extension Cuando dejo de responder. Este es el que va a usar mas
/chrome → Select browser…Fijar cual navegador usa
/mcp → claude-in-chrome Ver todas las herramientas del navegador, por curiosidad
Un consejo de plata. Hay una opcion en /chrome que dice «Enabled by default», para no escribir la bandera cada vez. No la active todavia. Deja las herramientas del navegador cargadas siempre y le come contexto aunque no las use. Mejor escriba claude --chrome los dias que lo necesite.

4

Si le pregunta «¿cual navegador?»

Lea esto ANTES de que le pase. Le va a pasar.

Compartimos una sola cuenta de Claude en el salon. Y la lista de navegadores conectados va por cuenta, no por computador. Traduccion: en su lista pueden aparecer navegadores de sus compañeros, con nombres inutiles como Browser 1 y Browser 2.

No adivine y no escoja de una. Si escoge el equivocado, le va a abrir pestañas en el computador de un compañero. Nadie se muere, pero es un desorden y perdemos la clase.

Lo que hace en vez de adivinar. Pidale la lista completa:

Pegue esto cuando le pregunte cual navegador 
Corre list_connected_browsers y mostrame el resultado completo.
Despues usa el que tenga "isLocal": true, que ese es mi computador.
No corras switch_browser.

Le va a salir algo asi. Mire el ultimo dato de cada linea:

[{"deviceId":"1b433774-a436-4024-b4bf-f377abbe2c64",
  "name":"Browser 1","osPlatform":"Windows",
  "connectedAt":1787716247447,"isLocal":true}]
El suyo es el que dice "isLocal": true. Punto. Y nadie corre switch_browser.
Y esto es lo mas importante del paso: el numero CAMBIA. Browser 1 y Browser 2 no son nombres, son el puesto en la fila. Se reparten otra vez cada vez que se conecta o se desconecta alguien. El «Browser 1» de hoy puede ser el navegador de un compañero mañana. Por eso nunca escoja por el numero: escoja por isLocal.
Dato¿Sirve para saber si es el suyo?
"isLocal": trueSI. Es el unico que sirve. Mire este.
nameNO, y menos. Dice Browser 1, Browser 2… y el numero cambia de un dia a otro. Es el puesto en la fila, no un nombre. No se puede cambiar
osPlatformNO. Todos estamos en Windows
deviceIdSolo para señalarlo. Es un codigo, no dice de quien es
¿Le salieron DOS con isLocal: true? Entonces tiene la extension en dos navegadores del mismo computador. Quitela del que no usa (brave://extensions o chrome://extensions), corra /chrome → Reconnect extension, y liste otra vez.
Por que se prohibe switch_browser. Ese comando le manda una ventana emergente a TODOS los navegadores conectados a la cuenta, y se queda esperando hasta dos minutos. Si usted lo corre, les aparece a los otros quince. No lo corra.

Pidale a Claude que le deje la regla escrita. Asi no tiene que repetirlo cada clase:

Pegue esto UNA vez en Claude Code 
Crea el archivo  %USERPROFILE%\.claude\CLAUDE.md  (si ya existe, agregale
esto al final sin borrar lo que tenga) con este contenido:

## Navegador
Cuando vayas a usar el navegador:
1. Corre list_connected_browsers.
2. Escoge SIEMPRE el que tenga "isLocal": true. Ese es mi computador.

Por que en %USERPROFILE%\.claude\CLAUDE.md y no en la carpeta del proyecto: porque ahi aplica en cualquier carpeta donde usted trabaje. Si lo pone en una carpeta sola, al cambiar de proyecto se le olvida la regla.

Claude puede escribir ahi, pero a los tropezones. Un formulario si tiene campos reales, y ahi no se equivoca. Que NO intentar

Ni de prueba, ni «para ver que pasa».
Nada de banca. Nada de nomina. Nada de historias clinicas. Nada de cedulas. Anthropic bloquea las paginas de adultos y de contenido pirata, y las financieras le piden permiso aparte. Pero el bloqueo no es completo — ellos mismos lo dicen. La ultima linea de defensa es usted.
No haga estoPor que
Banca, inversiones, cripto, pagos Bloqueado o restringido. Y a Claude le esta prohibido hacer operaciones de bolsa
Enviar correos o mensajes reales Enviar pide confirmacion, pero un correo enviado no se devuelve
Comprar cualquier cosa Pide confirmacion. Igual: prohibido en clase
Usar su perfil personal del navegador Claude toma capturas de la pestaña y no puede filtrar lo sensible. Lo que este visible, lo ve
Pedirle que resuelva un CAPTCHA Le esta prohibido. Se detiene y se lo pide a usted. Es lo correcto
Pedirle que se loguee en un sitio No lo hace. Se detiene en el login y usted entra a mano
«Leeme toda la consola» Los logs son larguisimos y le queman el contexto. Digale que buscar
Grabar un GIF con su correo abierto La grabacion captura todo lo visible, cuentas incluidas
switch_browser Le manda una ventana emergente a los quince compañeros
Recomendacion del propio Anthropic: use un perfil de navegador aparte, sin su correo personal ni sus cuentas de trabajo. Un perfil limpio, solo para esto. Es el consejo mas barato y el que mas le sirve.
7

Cuando algo se dañe

Se va a dañar. Aqui esta la salida de cada caso.
El caso numero uno, y el que nadie adivina. Si en la pagina se abre una ventanita del navegador — de esas de Aceptar / Cancelar — Claude queda congelado. No esta pensando ni esta lento: no puede recibir ordenes mientras esa ventanita este abierta. Usted le da Aceptar con el mouse y despues le escribe «ya, segui».

Si en diez minutos no le sale: no se quede atras. Pegue el error en Claude Code y digale «esto me salio, arreglalo». Si sigue sin salir, avise en clase. Nadie se pierde el taller por una conexion.
