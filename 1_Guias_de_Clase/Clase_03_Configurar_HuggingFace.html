Conectar Hugging Face a Claude Code

Hugging Face es el repositorio más grande de modelos de IA abiertos. Conectarlo le da a su agente un banco de modelos que puede usar sin instalar nada: generar imágenes, editar fotos, extraer texto de un escaneo, hacer voz. Este anexo es el registro de cómo quedó configurado y sirve para repetirlo en otro equipo.
Antes de empezar: esto no descarga ningún modelo a su computador. Todo corre en los servidores de Hugging Face. Su equipo solo manda la orden y recibe el resultado.
1

Entender las dos puertas de entrada

Son dos cosas distintas y se confunden todo el tiempo

Hay dos maneras de llegar a Hugging Face, con permisos y caducidades diferentes. Conviene tener las dos, pero sabiendo para qué sirve cada una.

PuertaPara qué sirveCaduca
Servidor MCP Que el agente use el Hub por su cuenta: buscar modelos, leer archivos, ejecutar Spaces (imagen, video, OCR, voz) Sí. La sesión vence y toca volver a autenticar
Token de acceso Que sus scripts y la terminal entren: descargar, subir, llamar la API No, hasta que usted lo revoque

MCP significa Model Context Protocol: es el enchufe estándar con el que un agente se conecta a un servicio externo. Es lo mismo que vimos en clase con las demás herramientas.

2

Conectar el servidor MCP

Una línea en la terminal, más un permiso en el navegador
Pegue esto en la terminal 
claude mcp add hf-mcp-server -t http "https://huggingface.co/mcp?login"

Después, dentro de Claude Code, escriba /mcp, elija hf-mcp-server y dele Authenticate. Se le abre el navegador, entra con su cuenta de Hugging Face y acepta.

Si dice que ya existe: es que quedó registrado de un intento anterior. No es un error. Verifíquelo con claude mcp get hf-mcp-server; si sale Needs authentication, solo le falta el /mcp.
3

Crear el token de acceso

Con permisos justos, no con todos

Vaya a huggingface.co/settings/tokens y cree uno de tipo fine-grained (permisos finos). Póngale un nombre que diga para qué es —el de este equipo se llama Automatic_Workflows— y marque solo lo que va a usar:

repo.content.read      leer archivos de repositorios
repo.write             subir cosas a SUS repositorios
inference.serverless   llamar modelos por API (texto, voz, embeddings)
job.write              lanzar trabajos en la nube de Hugging Face
Por qué "fine-grained" y no el clásico: el token clásico puede hacer todo lo que usted puede hacer. Si se filtra, se filtró la cuenta entera. El de permisos finos solo puede hacer lo que usted marcó.
4

Guardar el token fuera del código

Esta es la parte que la gente hace mal

El token nunca se escribe dentro de un script ni se pega en un chat. Va en un archivo aparte llamado .env, que se queda en su máquina:

# C:\1_Automatic_Workflows\.env
HF_TOKEN=hf_xxxxxxxxxxxxxxxxxxxx

Y ese archivo se protege para que no se suba a ningún lado, con un .gitignore que lo excluya:

.env
.env.*
*.safetensors
*.gguf
Tres reglas que no se negocian:
  • Una sola copia. Si el token está en dos archivos, el día que lo rote uno queda viejo y algo falla sin avisar.
  • Nunca en un chat. Si lo pega en una conversación con una IA, queda en el historial. Rótelo.
  • Nunca en la nube. Ojo con carpetas sincronizadas con OneDrive o Drive.

En este equipo se decidió no usar hf auth login, porque ese comando guarda una segunda copia del token en otra carpeta. Con una sola copia, rotarlo es cambiar una línea y ya.

5

Instalar la herramienta de terminal

Y un cargador para no repetir el token nunca
Instalar 
pip install -U huggingface_hub

Eso instala la librería y el comando hf. Ahora hace falta que la terminal vea el token. En Windows con PowerShell se hace con un cargador —en este equipo está en tools\Load-Env.ps1— que lee el .env y lo pone en memoria:

Cargar el .env en la sesión 
. C:\1_Automatic_Workflows\tools\Load-Env.ps1
Ojo al punto del principio. Ese punto y el espacio no son un error de tipografía: le dicen a PowerShell que las variables se queden en la sesión. Sin el punto, el script corre, carga todo… y al terminar se pierde.
6

Comprobar que de verdad quedó

Tres pruebas, de la más barata a la más real
¿La terminal me reconoce? 
hf auth whoami

Debe responder con su usuario. Si dice Not logged in, no cargó el .env.

¿Qué permisos tiene el token? 
$r = Invoke-RestMethod -Uri "https://huggingface.co/api/whoami-v2" `
     -Headers @{ Authorization = "Bearer $env:HF_TOKEN" }
$r.name
$r.auth.accessToken.fineGrained.scoped.permissions
¿Sirve para pedirle algo a un modelo? 
$body = @{
  model      = "meta-llama/Llama-3.1-8B-Instruct"
  messages   = @(@{ role = "user"; content = "Responde exactamente: funciona" })
  max_tokens = 10
} | ConvertTo-Json -Depth 5 -Compress

Invoke-RestMethod -Uri "https://router.huggingface.co/v1/chat/completions" -Method Post `
  -Headers @{ Authorization = "Bearer $env:HF_TOKEN"; "Content-Type" = "application/json" } `
  -Body $body
Dato útil: esa dirección habla el mismo idioma que la API de OpenAI. O sea que cualquier programa hecho para OpenAI funciona con Hugging Face cambiándole una sola línea: la base_url. No hay que reescribir nada.
7

Enseñarle a su agente a usarlo bien

Una skill, como las que vimos en clase
Instalar la skill 
hf skills add -g --claude

Esto le instala a Claude un manual del comando hf, para que no se lo invente. La bandera -g es global: queda disponible en todos sus proyectos, no solo en el de ahora. Se desinstala borrando la carpeta .claude\skills\hf-cli.

8

Qué se puede hacer y qué no

Con el plan gratuito, sin instalar nada
TareaSirve para
Generar imágenesPiezas de mercadeo, ilustraciones, bocetos de producto
Editar imágenesQuitar objetos, cambiar el fondo, restaurar fotos viejas, ampliar el encuadre
Quitar el fondoFotos de producto, retratos para catálogo
OCRSacar el texto de un contrato escaneado o una factura, conservando la estructura
VozNarrar un texto para un video o una capacitación
Video cortoAnimar una foto fija unos segundos
Texto y embeddingsModelos de lenguaje por API, buscadores semánticos
Los límites del plan gratuito, dichos claro:
  • Las GPU compartidas tienen cuota diaria y la fila da prioridad a quien paga.
  • La API de texto trae un crédito mensual muy pequeño. Alcanza para probar, no para producción.
  • El video es lo más pesado: a veces se demora tanto que se cae.
Sirve de sobra para aprender y para prototipos. Para volumen real, toca plan pago o modelos locales.
9

Si algún día lo corre en su propio computador

Dos trampas que cuestan horas

Bajar un modelo y correrlo en su máquina es gratis, privado e ilimitado. Pero hay dos cosas que casi nadie advierte:

  • Las tarjetas nuevas necesitan PyTorch nuevo. Una RTX 50xx (arquitectura Blackwell) no funciona con la instalación normal de PyTorch: hay que pedir la versión de CUDA 12.8 en adelante. Si no, sale el error no kernel image is available y parece que la tarjeta estuviera dañada. No lo está. 
    pip install torch --index-url https://download.pytorch.org/whl/cu128
  • La memoria RAM importa tanto como la tarjeta. El modelo primero se carga en la RAM del sistema y de ahí pasa a la tarjeta. Con 16 GB de RAM se queda corto aunque la tarjeta sea buena.
Cuánto pesa esto: un modelo de texto mediano son entre 8 y 30 GB en disco. Si va a bajar varios, revise el espacio antes y déjelos fuera de las carpetas que sincroniza con la nube.

Mantenimiento

Lo que se rompe con el tiempo
SíntomaQué pasóSolución
El agente ya no ve Hugging Face Venció la sesión del MCP /mcp y autenticar otra vez
hf auth whoami dice Not logged in No se cargó el .env en esta terminal Correr el cargador con el punto adelante
Error 401 en los scripts Token revocado o mal copiado Crear uno nuevo y cambiar la línea del .env
Error 402 o "quota" Se acabó el crédito o la cuota diaria Esperar al otro día o pasar a plan pago
El token quedó expuesto Se pegó en un chat, un correo o un repositorio Revocarlo ya y crear otro. No sirve borrar el mensaje
La idea de fondo: ninguno de estos pasos es programar. Es conectar servicios y guardar bien una llave. Eso es exactamente lo que se espera de un gerente que manda sobre la IA: saber qué se conecta con qué, qué cuesta, y dónde está el riesgo.
