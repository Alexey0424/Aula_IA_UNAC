Deje su computador listo para trabajar

Al terminar esta guía, Visual Studio Code le abre Word, Excel, PowerPoint y PDF sin salirse, y la barra de abajo de Claude Code le dice en todo momento qué modelo está usando, cuánto contexto le queda y cuánta plata lleva gastada.

Usted no va a configurar nada a mano. Se lo va a pedir a Claude Code, que para eso lo instalamos.

Antes de empezar. Necesita tener ya instalado lo de la Clase 02: Visual Studio Code y Claude Code funcionando. Si escribe claude --version en la terminal y le responde un número, está listo. Si no, primero eso.
1

Abra Claude Code adentro de Visual Studio Code

Es donde va a vivir de aquí en adelante.
  1. Abra Visual Studio Code.
  2. Archivo → Abrir carpeta y escoja una carpeta suya de verdad, con documentos de trabajo. No el escritorio, y no una carpeta sincronizada con OneDrive: da problemas de permisos.
  3. Abra la terminal con Ctrl + Ñ (o Terminal → Nueva terminal).
  4. Escriba claude y Enter.
Cómo sabe que quedó bien: la terminal deja de verse como una terminal y aparece el cuadro donde usted le escribe a Claude.
2

Pídale que instale las extensiones

Copie el bloque completo, péguelo en Claude Code y déle Enter.

Esto es lo que hace que un .xlsx se vea como una hoja de cálculo y no como un montón de símbolos raros.

Le va a pedir permiso antes de tocar archivos. Léalo y apruébelo. Ese es el punto de todo esto: usted sigue mandando.

Lo que le va a pasar y no es un error. Al hacer doble clic sobre un .docx ya no se ve texto plano: se ve el documento. Si algún archivo se le abre todavía como símbolos, clic derecho sobre él → Volver a abrir el editor con… → Office Viewer → marque Configurar predeterminado.

3

Pídale que le arme el tablero de la parte de abajo

La barra de estado. Es su tablero de instrumentos.

Sin esto, usted no sabe con qué modelo está trabajando, ni cuánto contexto le queda, ni cuánto lleva gastado. Es como manejar sin tablero.

Pegue esto en Claude Code 
Armame la barra de estado de Claude Code. Quiero DOS lineas.

Linea 1, en este orden: el modelo que estoy usando, el nivel de esfuerzo, y las
tres ventanas — cuanto llevo de la ventana de contexto, cuanto llevo del limite
de 5 horas y cuanto llevo del limite semanal. Cada una con una barrita y su
porcentaje, y al lado cuanto falta para que se reinicie.

Linea 2, en este orden: el nombre de la carpeta en la que estoy trabajando,
cuanta plata llevo gastada en esta sesion, cuanto tiempo llevo, si tengo el
pensamiento extendido prendido, y la version de Claude Code.

Reglas de diseno, importantes:
- Que se ADAPTE al ancho de la ventana. Lee la variable de entorno COLUMNS y si
  la terminal es angosta, encoge las barras y quita lo opcional. No quiero que
  se me monte una cosa sobre otra ni que se parta en varias lineas.
- Colores tranquilos: maximo cuatro. Un dorado suave para el modelo y la
  carpeta, grises para las etiquetas y las cifras, y el verde/ambar/rojo
  UNICAMENTE para los medidores. Nada de azul brillante ni de morado.
- Usa codigos de 256 colores, no los 8 basicos: los basicos los repinta el tema
  de la terminal y quedan chillones.
- El separador entre datos que sea corto.

Es Windows con PowerShell. Dos advertencias que ya me costaron caro:
- No escribas ningun caracter raro directo en el .ps1. PowerShell 5.1 lee los
  archivos sin BOM como ANSI y los parte en dos. Todo simbolo va con [char]0xNNNN.
- Escribi la salida como bytes UTF-8 directo a la salida estandar, no con
  Write-Output, porque si no se danan las barritas.

Cuando termines, probala con datos de mentiras a 120, a 90 y a 70 columnas y
mostrame como se ve en cada ancho.
Cómo sabe que quedó bien: abajo del cuadro donde usted escribe aparecen dos renglones con su modelo, unas barritas de colores y un valor en dólares. Si no aparece nada, salga con /exit y vuelva a entrar con claude.

Si prefiere no pedírselo y ponerlo ya hecho, el archivo 8_statusline.ps1 viene con el material de la clase. Se guarda en C:\Users\SU-USUARIO\.claude\statusline.ps1 y se agrega este bloque al settings.json de Claude Code (que es otro archivo distinto, está en C:\Users\SU-USUARIO\.claude\settings.json):

{
  "statusLine": {
    "type": "command",
    "command": "powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File \"C:/Users/SU-USUARIO/.claude/statusline.ps1\"",
    "padding": 0,
    "refreshInterval": 60
  }
}
Ojo con las barras. En esa ruta van barras hacia adelante (/), no hacia atrás. Si tiene Git instalado, Claude Code corre este comando a través de Git Bash, que se come las barras invertidas y falla sin decir nada.
